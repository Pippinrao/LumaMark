# Typora 专题竞争分析索引

本目录用于导航 LumaMark 对照 Typora 公开行为基线形成的 18 份专题竞争分析，并约束这些报告的职责、证据边界和维护方式。

## Parity Reliability 快照说明（2026-08-02）

本目录专题正文中的“执行摘要”“LumaMark 当前状态”和差距矩阵是 **2026-07-12 分析快照**，保留用于历史取证，不能脱离专题顶部较新的实施更新来判断当前能力。当前唯一执行路线见 [Typora Parity 核心体验改进计划](../../roadmap/TYPORA_PARITY_IMPLEMENTATION_PLAN.md)。

本轮已对段落、引用、列表、行内 span、脚注、水平线、YAML Front Matter、`[toc]` 和 Callout 补充 2026-07-27 实施更新。其中脚注、YAML、`[toc]` 与 Callout 目前只有 protected-source 安全降级，完整能力仍分别处于 Next 或 Later，不能标记为已实现。

2026-08-02 菜单系统改造又补充了标题、图片、代码块、表格和水平线专题顶部的实施更新。更新只确认真实菜单入口、快捷键与已有 capability 的接线，不改变各专题对编辑模型、源码保真和边界能力的总体判断。菜单的结构、命令合同和跨专题覆盖矩阵见 [LumaMark 菜单系统设计](../MENU_SYSTEM_DESIGN.md)。

## 用途

- 为产品、UX、编辑器实现和验收人员提供按专题查找当前差距的入口。
- 固定每份报告的主题边界，避免同一差距在多个专题重复维护。
- 统一 LumaMark 实现状态、差距严重度和专题审查门禁。

## 范围

- 目录覆盖横切 Live Preview 模型及 17 个 Markdown 功能专题。
- 各专题只记录报告更新时可定位的 LumaMark 代码、测试、fixture、运行探针和用户路径证据，以及由这些证据支持的差距判断。
- 报告可以给出分阶段改进建议，但不得改变产品范围、架构原则或 Typora 行为事实。

## 非目标

- 本索引不汇总、排序或改写 18 份报告的功能结论。
- 本目录不是 Typora 行为事实库，不复制 Typora 基线正文，也不推断其私有实现。
- 本目录不是 LumaMark 产品规格、竞品战略、架构决策或实施计划的替代品。
- 报告不以规划文档、依赖存在或通用基础设施单独证明功能已经实现。

## 状态与严重度词表

### LumaMark 状态

| 取值 | 定义 |
|---|---|
| `已实现` | 当前仓库存在可定位的执行路径，并有与该结论范围相称的直接证据。 |
| `部分实现` | 主路径或基础设施存在，但入口、状态转换、边界、错误恢复、验收证据或完整体验仍有缺口。 |
| `未实现` | 未找到该能力所需的执行路径，或现有行为不能构成该专题能力。 |
| `证据不足` | 现有静态或运行证据不足以可靠判断；不得按已实现处理。 |

### 差距严重度

| 取值 | 定义 |
|---|---|
| `阻断` | 阻止核心写作闭环、可能破坏源码意图或涉及必须先解决的安全/数据风险。 |
| `高` | 明显影响高频工作流、交互可预测性或关键验收，但仍存在可用替代路径。 |
| `中` | 影响完整性、效率或边界体验，不阻断主要写作路径。 |
| `低` | 低频、精修、证据补强或有限范围的一致性差距。 |

状态描述证据完整度，严重度描述用户与产品影响，两者不得相互替代。分阶段优先级由各专题结合产品范围另行给出。

## 更新时机

出现以下任一情况时，复核受影响专题；横切行为变化时同时复核 `00-live-preview-model.md`：

- 相关编辑器 capability、命令、样式、服务、设置或文件链路发生变化。
- 新增、删除或修改了相关单元测试、集成测试、E2E、fixture、性能基准或运行探针。
- Typora 基线对应专题的事实、出处或复核状态发生变化。
- V1 范围、UX 目标、架构约束或竞品策略改变，导致差距判断或阶段建议需要调整。
- 依赖升级改变了解析、键位、渲染、安全或平台行为。

更新报告时只重评有新证据的结论，并保留证据的具体文件、测试或命令位置；不得因计划已写、依赖已安装或相邻功能存在而推断本专题已实现。
